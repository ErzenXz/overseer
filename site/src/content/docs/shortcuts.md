## Anywhere

| Shortcut | What it does |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Open the command palette: jump to any session, machine, setting or action |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>O</kbd> | New session |
| <kbd>⌘</kbd> <kbd>B</kbd> | Show or hide the sidebar |
| <kbd>/</kbd> | Search settings, on any Settings page |

![The command palette](shot:palette)

## In the message box

| Shortcut | What it does |
| --- | --- |
| <kbd>Enter</kbd> | Send |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | New line |
| <kbd>Shift</kbd> <kbd>Tab</kbd> | Switch to the agent's next mode |
| <kbd>/</kbd> | Show slash commands, in an empty message box |

## In the slash command list

| Shortcut | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the list |
| <kbd>Enter</kbd> or <kbd>Tab</kbd> | Use the highlighted command |
| <kbd>Esc</kbd> | Close the list and clear the box |

## In dialogs and menus

| Shortcut | What it does |
| --- | --- |
| <kbd>Esc</kbd> | Close |
| <kbd>Tab</kbd> | Move between fields; focus stays inside the dialog |
