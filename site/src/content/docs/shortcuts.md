## Anywhere

| Shortcut | What it does |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Search sessions, machines, pages and actions |
| <kbd>?</kbd> | Show all shortcuts |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> | New session |
| <kbd>⌘</kbd> <kbd>J</kbd> | All sessions |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |
| <kbd>⌘</kbd> <kbd>B</kbd> | Show or hide the sessions panel |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>L</kbd> | Switch between light and dark |
| <kbd>/</kbd> | Jump to the message box |

## Go to a page

Press <kbd>G</kbd>, then a letter. A small hint at the bottom of the screen lists the choices.

| Keys | Page |
| --- | --- |
| <kbd>G</kbd> <kbd>N</kbd> | New session |
| <kbd>G</kbd> <kbd>S</kbd> | All sessions |
| <kbd>G</kbd> <kbd>A</kbd> | Automations |
| <kbd>G</kbd> <kbd>R</kbd> | Review |
| <kbd>G</kbd> <kbd>V</kbd> | Agent Arena |
| <kbd>G</kbd> <kbd>M</kbd> | Machines |
| <kbd>G</kbd> <kbd>O</kbd> | Mission control |
| <kbd>G</kbd> <kbd>W</kbd> | Agent Wrapped |
| <kbd>G</kbd> <kbd>K</kbd> | Skills & plugins |
| <kbd>G</kbd> <kbd>P</kbd> | Projects |
| <kbd>G</kbd> <kbd>C</kbd> | Customize |
| <kbd>G</kbd> <kbd>U</kbd> | Usage & limits |
| <kbd>G</kbd> <kbd>I</kbd> | Keyboard shortcuts |
| <kbd>G</kbd> <kbd>,</kbd> | Settings |

> [!TIP]
> One-key shortcuts like <kbd>G</kbd> and <kbd>?</kbd> only work when you aren't typing in a box. Press <kbd>Esc</kbd> to leave the message box first.

## In a session

| Shortcut | What it does |
| --- | --- |
| <kbd>⌥</kbd> <kbd>↑</kbd> / <kbd>⌥</kbd> <kbd>↓</kbd> | Previous or next session |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Allow what the agent asks (Allow once), when the message box is empty |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>⌫</kbd> | Reject what the agent asks |
| <kbd>⌘</kbd> <kbd>.</kbd> | Stop the agent |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>P</kbd> | Show or hide the workspace |
| <kbd>⌥</kbd> <kbd>1</kbd> … <kbd>⌥</kbd> <kbd>6</kbd> | Open the shell, preview, desktop, files, changes or plan |
| <kbd>⌥</kbd> <kbd>0</kbd> | Close the workspace |

## In the message box

| Shortcut | What it does |
| --- | --- |
| <kbd>↵</kbd> | Send |
| <kbd>⇧</kbd> <kbd>↵</kbd> | New line |
| <kbd>⇧</kbd> <kbd>Tab</kbd> | Switch to the agent's next mode |
| <kbd>/</kbd> | Show commands, in an empty box |
| <kbd>Esc</kbd> | Close a menu or dialog, or leave the box |

## Mission control

| Shortcut | What it does |
| --- | --- |
| <kbd>F</kbd> | Full screen (TV mode) |
| <kbd>Esc</kbd> | Leave full screen |

> [!TIP]
> Your browser keeps a few shortcuts for itself, and some of them (like <kbd>⌘</kbd> <kbd>,</kbd> in Chrome) can't be overridden. If one doesn't work in your browser, <kbd>⌘</kbd> <kbd>K</kbd> and the <kbd>G</kbd> shortcuts always do.
